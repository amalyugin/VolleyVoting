ЗАПУСК РАСЧЕТА СТАТИСТИКИ:
1. Открыть launch.bat для редактирования. Поменять параметры: названия файла данных, название файла результатов, номер начального тура, номер конечного тура
2. Запустить laubch.bat, в этой же директории должен появиться файл результатов

Расчет статистики идет от начального до конечного тура. Тур из регулярки обозначается обычным числом, Тур в плейофф, пример: 1/2_3 - полуфинал, 3 тур

ФАЙЛ ДАННЫХ (пример: data.txt)
Должен быть в кодировке windows-1251 (В редакторе открыть файл, изменить кодировку). Можно взять файл data.txt и его править.
Все что написано в строке после символа # комментарии, они игнорируются.
Пустые строки игнорируются, можно их вставлять для разделения блоков и голосований.
Регистр в именах и названиях не учитывается, т. е. Лазарева, лазарева, ЛАЗАРЕВА, ЛаЗаРеВа это одно и то же.

Список команд, пример:
команды: корабелка ленинградка акбарс уралочка краснодар енисей динамо омичка протон заречье метар локомотив тулица минчанка

Далее идут тройки голосования, каждая тройка - отдельная строка.

формат строки голосования:
номер тура, сокращение команды хозяев, сокращение команды гостей, игрок 1, игрок 2, игрок 3, никнейм проголосовавшего

пример:
10 мин акб Мартинес Матвеева Турчина sovtsova

Сокращение команды происходит от имени команды в строке команд, сокращение должно быть уникально. Пример, для заречье можно использовать: за, зар, заре, зареч 
Никнейм проголосовавшего для человека должен быть везде одним и тем же.
Имена игроков - фамилии полностью, без сокращений. Если игроков с одной фамилией несколько то можно изменить фамилию для уникальности, например: еклазарева.
Для игрока должна быть выбрана одна фамилия на все туры.


ФАЙЛ РЕЗУЛЬТАТОВ:
Появляется или обновляется после запуска launch.dat.
SUM METHOD - метод суммиривания голосований.
AVERAGE METHOD - метод осреднения по матчу.

строки типа:
add player 128 = булгакова  line 313
говорят о строке в файле данных, когда впервые появилась игрок.
Проверять эти строки полезно для проверки наличия дублирования игрока (Державина/Костючик), для проверки опечаток (буквы е, ё; др.)
